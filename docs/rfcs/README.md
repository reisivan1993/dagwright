# RFC process

Use an RFC for public contracts, architecture, compatibility, governance, or changes spanning more
than one module. Copy `0000-template.md`, assign the next number, and open it as a pull request.

An RFC moves from Draft to Accepted, Rejected, or Withdrawn. Authors summarize alternatives and
resolve feedback in public. Maintainers accept through documented lazy consensus; acceptance means
the direction is agreed, not that implementation is complete. Material changes after acceptance
require an amendment or superseding RFC.

Accepted RFCs include [RFC-0006: Local read-only Viewer](0006-local-read-only-viewer.md).
