# v0.3 checkpoint 1: read-only local Viewer

The optional Viewer makes DAGwright’s existing deterministic compiler output easier to understand.
It is a local developer tool, not a production control plane.

```sh
uv sync --locked --all-groups
uv run dagwright ui examples/customer-analytics/dataproduct.yaml
```

The command validates and compiles the selected DataProduct before it starts an HTTP server on
`127.0.0.1:8787`. If compilation fails, no server starts. The browser displays:

- product metadata and content digests;
- the engine-neutral dependency graph and topological execution plan;
- normalized contract and canonical IR JSON;
- generated Airflow 3 and Spark/Iceberg artifacts;
- the deterministic compilation manifest.

Use `--overlay PATH` repeatedly to inspect an effective environment contract. Use `--port PORT` to
select another loopback port and `--no-open` for headless environments.

The server exposes only packaged static files and one precomputed JSON snapshot. It has no write
endpoint, file-path endpoint, upload, editor, deployment action, external asset, cookie, or remote
binding option. Responses disable caching and include a restrictive Content Security Policy. All
contract and generated content is inserted into the page with text-only DOM APIs.

The CLI and compiler remain authoritative. Closing the command stops the Viewer, and nothing is
stored, executed, or deployed.
