# v0.2.0 release candidate

`0.2.0rc1` is a local review candidate for the completed deterministic compiler, verification, and
overlay checkpoints. It is not a published release and is not an ASF release.

Run:

```sh
make release-candidate
```

The target first runs the normal static, test, schema, adapter, and vulnerability gates. It then
uses the current Git commit time as `SOURCE_DATE_EPOCH`, builds the source distribution and wheel
twice in separate temporary directories, and rejects any byte difference. The candidate wheel is
installed into an isolated Python 3.12 environment and exercised through the public CLI.

Review files under `build/release/0.2.0rc1/`:

- `dagwright-0.2.0rc1.tar.gz` and `dagwright-0.2.0rc1-py3-none-any.whl`;
- `SHA512SUMS` for every candidate review artifact;
- `dagwright.cdx.json`, a deterministic CycloneDX 1.6 inventory of the locked default runtime;
- `dependency-licenses.md`, which highlights missing or non-normalized upstream license metadata.

The SBOM describes the default compiler installation, not the optional Spark execution environment
or contributor tooling. Dependency license declarations are evidence for human review, not an
automated legal conclusion.

The command intentionally does not create a Git tag, sign artifacts, upload to PyPI, create a
GitHub release, or change repository visibility. Those actions require explicit release-manager
authorization after the checklist, maintainer review, provenance, and signing requirements are met.
