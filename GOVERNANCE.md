# Governance

DAGwright is developed in public through issues, pull requests, RFCs, and recorded decisions.
Maintainers merge changes based on technical merit, project scope, review, and verification—not
employer affiliation. Significant decisions should seek lazy consensus after allowing reasonable
time for community review; unresolved objections are documented and handled by maintainers.

Committer and maintainer responsibilities are earned through sustained, constructive contribution.
As the community grows, nominations and decisions will be recorded publicly and the governance
model will evolve through RFCs. Security reports follow [SECURITY.md](SECURITY.md).

DAGwright is not currently an Apache Software Foundation project. The project aims to cultivate the
independent community, transparent governance, licensing discipline, and release practices expected
of a possible future incubation proposal without claiming ASF endorsement.
