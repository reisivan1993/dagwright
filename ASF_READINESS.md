# Apache-style project readiness

DAGwright uses Apache License 2.0 and aspires to practices compatible with possible future Apache
Incubator consideration. It is not an Apache Software Foundation project and does not claim ASF
endorsement.

## Present foundations

- Apache-2.0 `LICENSE`, `NOTICE`, DCO, contribution guide, code of conduct, security policy, and
  public governance model.
- Decisions recorded through public ADRs/RFCs and changes verified by reproducible CI.
- Engine-neutral compiler contracts and deterministic, reviewable artifacts.

## Required before an incubation proposal

- [ ] Operate the repository publicly with an independent, diverse contributor community.
- [ ] Publish named maintainers, transparent voting/consensus records, and a documented release team.
- [ ] Complete trademark/name clearance and avoid Apache marks before acceptance.
- [ ] Establish private security reporting, disclosure timelines, and release signing keys.
- [ ] Audit provenance and licenses for every dependency, source file, generated artifact, and asset.
- [ ] Demonstrate multiple community-reviewed releases with reproducible source artifacts.
- [ ] Identify prospective mentors and prepare an Incubator proposal only with community consensus.
